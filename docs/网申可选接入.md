# 网申可选接入

核心可以独立准备文案、PDF 和本地网申记录。实网页面、浏览器登录、扩展和平台适配工具由使用者另行配置。本项目不包含这些脚本、扩展、浏览器配置、账号、已保存表单或私人字段表。

| 选择的工作 | 所需组件 |
| --- | --- |
| 只制稿、转 PDF | 本机 Chrome/Edge、Node.js 22+。程序从本地文件渲染，和网申登录态分开。 |
| 使用另行取得的网申适配器 | 依据该工具的单独许可、支持的平台和说明安装。Node 脚本若使用全局 `WebSocket`，选受工具实测的较新版本。以新建专用浏览器配置开始，使用者自行登录。浏览器配置和账户由使用者自己管理。 |
| Moka 首轮辅助功能 | 如使用依赖「牛客助手」的首轮模式，单独安装可信来源的扩展并按站点提示登录；人工填写、只读检查和二轮对齐的依赖分开。 |
| 其他平台或校招采集 | 按选中的平台功能准备。Browser4 是某些采集流程的可选运行时；不接它也能跑核心流程与本地示例。OpenSpec 只用于相关开发任务。 |

启动实测前，确认实际站点、岗位、操作范围及待核资料。解析、实际附件、暂存和提交在网页上可能是四个不同动作。若有独立附件字段，按浏览器显示核对文件名与附件区，保存后从投递记录重开同一草稿，再核正文与附件是否仍在。若无该字段，记录网站限制。工具的“只读”可能仍写本地报告，应留在私人数据区，不带入分发包。
